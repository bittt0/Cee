Swordfight!!

Download Now

This game is in active development, and can be played in browser on mobile and PC.

Swordfight!! is a top-down fighting game featuring:

  • 11 unique characters to fight against! (and more to come)
  • An original soundtrack with themes for each character.
  • A leaderboard displaying the top 20 times for each level.
  • Support for mobile controls.

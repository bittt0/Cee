How to add games:
  1. Place extracted game folder at /games/your-game/ (index.html inside).
  2. Add a link card above (copy the Idle Breakout card and change href/title/icon).
  3. Commit & push to GitHub — your game will be live at /games/your-game/index.html.

Tip: test locally with python -m http.server in your repo root.

Client-side password — not secure for secrets. Change PASSWORD in the HTML to your chosen password before pushing.
